# Higiene ERP — demonstração do frontend

Interface demonstrativa para controle de pragas e serviços ambientais.

- Dados fictícios e alterações somente na memória da aba.
- Recarregar descarta cadastros, relatórios e fotos adicionados durante o teste.
- Nenhuma NFS-e é transmitida e nenhuma conta real é criada.
- Não informe dados pessoais, credenciais ou dados reais da empresa.

Este repositório contém somente o artefato estático verificado. O código-fonte do ERP, o servidor e o banco MySQL permanecem no projeto de desenvolvimento local.

Publicação: https://btcsolucoes.github.io/higiene-erp/
